# Login Canvas

A modern WordPress login page customization plugin that helps you create
a branded and professional login experience.

## Overview

Login Canvas allows WordPress administrators to customize the default
login page with a clean, responsive, and modern design.

The plugin focuses on improving the visual experience of the WordPress
login screen while keeping the native authentication system untouched.

## Features

-   Custom login page design
-   Custom logo support
-   Responsive layout
-   RTL and LTR language support
-   Persian and English font support
-   Modern form styling
-   Lightweight WordPress integration
-   Compatible with WordPress authentication flows

## Installation

1.  Download the latest release.
2.  Upload the plugin folder to `/wp-content/plugins/`.
3.  Activate Login Canvas from the WordPress admin panel.
4.  Configure the plugin settings.
